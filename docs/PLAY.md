# HorizonRunner — 遊び方

この文書は、HorizonRunner を遊ぶために必要なこと (配布物からの起動の仕方、操作、ゲームの流れ) を説明します。
配布物をソースから作る手順は [BUILD.md](BUILD.md) を、中の作りは [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。

## 1. 配布物

| ファイル | 使い方 |
|---|---|
| `disks/horizonrunner.d77` | ディスクから起動します |
| `disks/horizonrunner.t77` | テープイメージから読み込みます |
| `disks/horizonrunner.wav` | 音声をカセットの入力へ流して読み込みます |
| `disks/horizonrunner.cmt.txt` | テープからのロード手順 (テープを使う時に手元に置くテキストです) |

どの方法でも、イメージファイルをディスクやテープとして使える状態にしてから始めます。
実際のディスクやテープに書き出して使う場合、書き出しの方法は使う機器によるので、この文書では扱いません。

## 2. ディスクイメージから起動する

`disks/horizonrunner.d77` を 1 台目のドライブ (ドライブ 0) のディスクとして入れた状態で、電源を入れるかリセットします。
ディスクから本体が自動で読み込まれ、読み終わるとタイトル画面が出ます。

## 3. テープイメージから起動する

`disks/horizonrunner.t77` には、先頭から BASIC のローダー (`LOADER`) と本体の機械語ファイル (`C01`) の 2 つのファイルが入っています。
テープを先頭に戻した状態で入れ、F-BASIC が入力待ち (`Ready` の表示) になっているところから始めます。
次の 1 行を入力します。

```
RUN "CAS0:"
```

ローダーが `LOADING - PLEASE WAIT ABOUT 4 MIN` と表示し、続けて本体を読み込みます。
本体の機械語ファイルの読み込みには約 4 分 (227 秒) 掛かります。
ローダーから呼んだ読み込みは途中経過を表示しないので、その間は画面が止まったままに見えますが正常です。
読み終わるとそのままタイトル画面が出ます。

この 1 行で読み込めない時は、テープを先頭に戻してから、`disks/horizonrunner.cmt.txt` の「手で打つ手順」に従って `CLEAR ,&H13FF` と `LOADM "CAS0:C01",,R` を 1 行ずつ入力します。
同じテキストに、打ち間違えた時の表示と直し方も書いてあります。

## 4. WAV から起動する

`disks/horizonrunner.wav` は、T77 と同じ内容をカセットの音声にしたものです。
F-BASIC が入力待ちになっているところで `RUN "CAS0:"` を入力し、WAV を先頭から再生してカセットの入力へ流します。
その後の進み方はテープイメージの時と同じです (WAV 全体の長さは末尾の無音を含めて約 250 秒で、そのうち本体の機械語ファイルの部分が約 227 秒です)。

## 5. 操作

| キー | 働き |
|---|---|
| テンキー 8 / 2 / 4 / 6 | 上 / 下 / 左 / 右へ動きます |
| テンキー 7 / 9 / 1 / 3 | 左上 / 右上 / 左下 / 右下へ動きます |
| テンキー 5 | 止まります |
| カーソルキー | テンキー 8 / 2 / 4 / 6 と同じです |
| BREAK | ショットを撃ちます。押し続けると連射します |
| BREAK または RETURN | タイトル画面でゲームを始めます |
| ESC | ゲームオーバーの画面が出てから約 2 秒後に押すと、すぐタイトル画面へ戻ります (押したままでは戻りません) |

タイトル画面の下にも、テンキーの図と同じ操作の説明が出ます。

自機は、キーを離しても動き続けます。
止める時はテンキー 5 を押します。
縦の向きと横の向きは別々に保たれるので、8 (上) の後に 6 (右) を押すと右上へ動きます。

## 6. ゲームの流れ

1. タイトル画面にはタイトルの文字、ハイスコア (`HI`)、流れる床、テンキーの図が出ます。BREAK か RETURN を押すと始まります。ゲームオーバーの画面から BREAK を押したまま戻って来ても始まりません。BREAK が押されておらず、RETURN のキーコードも来ない状態が約 1 秒続いた後に押すと始まります。
2. 自機は 5 機で、画面上の `REST` が残りの数です。BGM はステージの中だけ鳴り、タイトル画面とゲームオーバーの画面では鳴りません。
3. 敵、岩、ボス、敵の弾、地上の木や低木に当たると、画面が止まって自機の爆発を見せ、自機を 1 機失います。当たり判定は自機の絵より一回り小さく、敵・岩・木・低木にはかすった程度では当たりません (ボスと敵の弾は触れると当たります)。再開してから約 4 秒は自機が点滅し、何にも当たりません。
4. ステージの最後に、体が 7 つの節に分かれた蛇のようなボスが出ます。弾が効くのは頭だけで、12 発当てると倒せます。
5. ボスを倒すと `STAGE CLEAR` と表示され、表示が消えた後にステージの最初の編隊からそのまま続きます。
6. 自機がなくなるとゲームオーバーの画面になり、`GAME OVER`、得点 (`SCORE`)、ハイスコア (`HI`) を表示します。約 10 秒でタイトル画面へ戻ります。表示から約 2 秒たった後に ESC キーを押すと、すぐタイトル画面へ戻ります (受け付けるのは、ESC のキーコードが約 1 秒途切れた後の押下だけです。押したままでは戻りません。BREAK や RETURN でも戻りません)。
7. ハイスコアはゲームを起動している間保持され、再起動すると消えます。プレイ中の `HI` の表示はそのプレイを始めた時の値のままで、得点がハイスコアを越えても次の画面 (ゲームオーバーの画面) までは書き直されません。

得点は次のとおりです。

| 倒したもの | 得点 |
|---|---|
| 敵・岩 | 200 |
| 低木 | 50 |
| ボス | 5000 |

木は撃っても壊れません。
